## 6. mein / dein / sein / ihr

| 💬 جواب                                                                                          | ❓ سؤال                                                             |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| **Das ist mein Bruder.**<br>داس ایست ماین برودر<br>این برادر من است.                             | **Ist das dein Bruder?**<br>ایست داس داین برودر<br>این برادر توست؟ |
| **Ja, das ist mein Bruder.**<br>یا، داس ایست ماین برودر<br>بله، برادر من است.                    | **Ist das dein Bruder?**                                           |
| **Nein, das ist nicht mein Bruder.**<br>ناین، داس ایست نیشت ماین برودر<br>نه، این برادر من نیست. | **Ist das dein Bruder?**                                           |
| **Das ist meine Schwester.**<br>داس ایست ماینِ شوِستِر<br>این خواهر من است.                      | **Ist das deine Schwester?**                                       |
| **Das ist sein Bruder.**<br>داس ایست زاین برودر<br>این برادر اوست.                               | **Wer ist der Mann?**<br>این مرد کیست؟                             |
| **Das ist seine Schwester.**<br>داس ایست زاینِ شوِستِر<br>این خواهر اوست.                        | **Wer ist seine Schwester?**<br>خواهر او کیست؟                     |
| **Das ist ihr Bruder.**<br>داس ایست ایر برودر<br>این برادر اوست.                                 | **Wer ist ihr Bruder?**<br>برادر او کیست؟                          |
| **Das sind ihre Eltern.**<br>داس زیند ایرِ اِلترن<br>این‌ها والدین او هستند.                     | **Wer sind ihre Eltern?**<br>والدین او چه کسانی هستند؟             |

**نکته مهم:**
`sein` = مال او، وقتی صاحب **مذکر یا خنثی** است.
`ihr` = مال او، وقتی صاحب **مونث** است یا «آنها».

### بخش ۲: زبان

**A:** Welche Sprachen sprichst du?
وِلشِ شپغاخِن شپریخست دو؟
چه زبان‌هایی صحبت می‌کنی؟

**B:** Ich spreche Persisch und Deutsch.
ایخ شپغِخِ پِرشیش اونت دویچ.
فارسی و آلمانی صحبت می‌کنم.

**A:** Sprichst du Englisch?
شپریخست دو اِنگلیش؟
انگلیسی صحبت می‌کنی؟

**B:** Ja, ein bisschen.
یا، آین بیسخِن.
بله، کمی.

**A:** Wie schreibt man deinen Namen?
وی شرایبت مان داینِن نامِن؟
اسمت را چطور می‌نویسند؟

**B:** A-M-I-R.
آ ـ اِم ـ ای ـ اِر.

### بخش ۳: خانواده

**A:** Hast du Geschwister?
هاست دو گِشوِستِر؟
خواهر و برادر داری؟

**B:** Ja, ich habe zwei Brüder.
یا، ایخ هابِ تسوای بریودِر.
بله، دو برادر دارم.

**A:** Hast du eine Schwester?
هاست دو آینِ شوِستِر؟
خواهر داری؟

**B:** Nein, ich habe keine Schwester.
ناین، ایخ هابِ کاینِ شوِستِر.
نه، خواهر ندارم.

**A:** Wer ist das?
وِر ایست داس؟
این کیست؟

**B:** Das ist mein Bruder.
داس ایست ماین برودر.
این برادر من است.

**A:** Wie alt ist dein Bruder?
وی آلت ایست داین برودر؟
برادرت چند ساله است؟

**B:** Er ist 30 Jahre alt.
اِر ایست درایسیش یارِ آلت.
او ۳۰ ساله است.

### بخش ۴: شغل

### بخش ۵: غذا و نوشیدنی

**A:** Was isst du gern?

**B:** Ich trinke gern Tee.

قهوه می‌خواهی؟

**B:** Nein, danke. Ich möchte Tee.
ناین، دانکِ. ایخ مِشتِ تِه.

### بخش ۶: خرید

**A:** Was brauchen wir?

**B:** Wir brauchen Brot, Milch und Eier.

**A:** Wie viel kostet das?

**B:** Nein, das ist billig.
ناین، داس ایست بیلیش.
نه، ارزان است.

### بخش ۷: برنامه روزانه

**A:** Wann frühstückst du?

**B:** Ich frühstücke um halb acht.

**A:** Wann arbeitest du?
وان آربایتِست دو؟
کی کار می‌کنی؟

**B:** Ich arbeite um acht Uhr.
ایخ آربایتِ اوم آخت اوغ.
ساعت هشت کار می‌کنم.

**A:** Was machst du am Abend?
واس ماخست دو آم آبِنت؟
عصر چه کار می‌کنی؟

**B:** Ich kaufe ein, telefoniere und sehe fern.
ایخ کافِ آین، تِلِفونیرِ اونت زِه فِرن.
خرید می‌کنم، تلفن می‌کنم و تلویزیون تماشا می‌کنم.

**A:** Wann gehst du schlafen?
وان گِست دو شلافِن؟

ساعت ده‌ونیم می‌خوابم.

## ⭐ فرمول طلایی مرور

**Wer? → چه کسی؟ → Nominativ**

**Wen? → چه کسی را؟ → Akkusativ**

**Was? → چه چیزی؟**

**Wo? → کجا؟**

**Woher? → از کجا؟**

**Wie? → چگونه / چه‌طور؟**

**Wann? → کی؟**

**Wie viel? → چقدر؟**

**Wie viele? → چند تا؟**

**sein → بودن**

**haben → داشتن**

**möchten → خواستن مؤدبانه**

**nicht → منفی کردن فعل/صفت/جمله**

**kein → منفی کردن اسم**

**der → den در Akkusativ**

**ein → einen در Akkusativ**

**mein → meinen در Akkusativ**

**aufstehen / einkaufen / anrufen → فعل جداشدنی**

**um + Uhrzeit → ساعت**

**bei + Dativ → محل کار/نزد**

**als + Beruf → به‌عنوانِ شغل**

**für + Akkusativ → برای**

**man + فعل سوم‌شخص مفرد**

**جمله اصلی: فعل جایگاه دوم**

**فعل جداشدنی: بخش جداشده آخر جمله**
